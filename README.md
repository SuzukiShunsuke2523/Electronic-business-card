## 公開・更新

Cloudflare Pagesでmainを公開。静的サイトのためビルド処理は不要です。変更は作業ブランチとPull Requestで確認してからmainへ反映します。

顔写真とInstagramリンクはトップページに掲載済み。個人LINEのID・QR・追加URLは公開しません。勤務先や顧客の内部情報はコミットしないでください。
