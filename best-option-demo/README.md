# ベストオプション｜Web共有用プレビュー

同一LUNOA PILATES情報を5パターンでブラウザ確認するための軽量版。

- index.html：5パターンの入口
- demo.html?v=free：シンプル案
- demo.html?v=paid：こだわりデザイン案
- demo.html?v=interactive：料金切替・予約案内モーダル
- demo.html?v=colors：配色3案切替
- demo.html?v=media：イラストとCSSアニメーション。元の画像・7秒動画ファイルを含むローカル完成版とは異なる。

**注意：既存のローカル完成版と完全同一ではありません。** インタラクティブな実物にアクセスできるよう、HTML/CSS/JSを共有用に再構成しています。実店舗・実予約・決済・情報送信はなく、noindex。無料/有料AIの名称は制作方針の比較であってAI契約の比較試験結果ではありません。
