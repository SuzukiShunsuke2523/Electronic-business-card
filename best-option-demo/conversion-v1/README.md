# ベストオプション｜LUNOA PILATES 集客・予約導線重視デモ v1.0

制作日：2026-11-15
公開先：https://electronic-business-card.pages.dev/best-option-demo/conversion-v1/
比較対象：https://electronic-business-card.pages.dev/best-option-demo/interactive-v4/

## 目的
v4はビジュアル・アニメーションによる印象づけを重視するWOW版。
本デモは**見込み客が内容を把握し、料金を比較し、次の行動を決めやすい**ことを重視する集客・予約導線版。
実際の問い合わせ増加やCVR改善を実測・保証するものではありません。

## 仕様
- 架空ブランド：LUNOA PILATES
- 想定サービス：1対1のパーソナルピラティス（すべて架空設定）
- 掲載順：ファーストビュー → 特徴 → 雰囲気 → 料金 → 初回の流れ → FAQ → 最終CTA
- 初回体験：3,000円／50分、単発7,000円／50分、4回チケット26,000円（元デモと同じ）
- CTA：「まずは体験レッスンを見る」→料金→選択したプラン→「予約方法を見る」
- 予約案内ダイアログはデモ。顧客情報の収集、予約、決済、外部への送信なし
- 口コミ、店の所在地、スタッフ資格、営業実績等の未確認情報は捏造していない
- スマホ固定の料金導線、キーボード操作、native details/dialog、prefers-reduced-motion
- 実写フリー写真3点をPexelsから読み込み。動画の自動再生や外部JavaScriptライブラリは使わない
- 計測タグなし、noindex/nofollow

## WOW v4との比較

| 観点 | WOW v4 | 集客重視 v1 |
|---|---|---|
| ファーストビュー | 大胆な動きと世界観 | 誰向けか、体験価格、次の行動を明確化 |
| 素材 | 写真4点・自動再生動画1本 | 写真3点・動画なし |
| アニメーション | スクロール演出・文字演出多数 | スクロール時の軽い登場演出のみ |
| 料金 | 選択＋アニメーション数字 | 3案を比較＋選択内容・料金の要約 |
| 予約動線 | 予約案内を疑似体験 | 料金→予約案内のステップを明示 |
| 適した目的 | デザイン・技術の魅力を見せる | 顧客の理解と行動を支援する |

## 本番受注前の課題
1. 本物の屋号・メニュー・価格・FAQ・店舗所在地・予約方法を確認
2. 写真は可能なら店舗・講師の実物に置き換える（フリー写真を実店舗写真のように見せない）
3. 実際の公式LINE／予約サービスへの導線を顧客名義で設定
4. 重要事項（キャンセル規定・利用規約・個人情報保護）を顧客と確認
5. ページ速度・アクセシビリティとスマホ実機での表示検証
6. 商談前後で顧客が求める成果（案内時間削減、問い合わせ、予約）を確認し、計測方法を決める

**重要：本ページは2,000円モニターに含まれる納品内容そのものではなく、設計上の方向性を示す比較用デモ。**
