PROJECT 01 / NETWORK

Network Infrastructure Lab

小規模オフィスのネットワークを題材に、要件定義から設計、機器設定、検証、障害切り分けまでを段階的にまとめる自主制作プロジェクトです。

現在の状態：Packet Tracerで基本通信と障害演習を実測済み
架空の小規模オフィスを独立設計し、利用者がCisco Packet Tracerで構築・検証しました。必須通信試験9件で期待結果を確認し、設定ミス3種類の発生・切り分け・復旧も確認しました。実機試験・第三者による独立再現は未実施です。

01 / 想定要件

社員ネットワーク業務用端末から必要なサーバーへアクセス
サーバーネットワーク用途ごとに通信範囲を制御
ゲストネットワーク社内向けサーバーへのアクセスを禁止

主なテーマはVLANによる分離、VLAN間ルーティング、ACLによるアクセス制御、到達性・経路の確認です。外部インターネット接続はこの初期設計の検証範囲外です。

02 / 検証した論理構成

R1 — VLAN間ルーティング / ACL（Router-on-a-Stick）
↕ 802.1Q トランク
SW1 — L2スイッチ / VLAN 10・20・30
↓ アクセスポート
VLAN 10
社員
192.168.10.0/24
VLAN 20
サーバー
192.168.20.0/24
VLAN 30
ゲスト
192.168.30.0/24

各VLANのゲートウェイは末尾 .1。SW1 Gi0/1とR1 Gi0/0を802.1Q Trunkで接続し、サブインターフェースにACLを適用しました。

03 / 構築・検証プロセス

  1. 要件と通信許可・拒否条件を定義する
  2. アドレス設計とVLAN構成を確定する
  3. スイッチのVLAN・アクセスポート・トランクを設定する
  4. ルーターのサブインターフェースでVLAN間通信を設定する
  5. ACLでゲストからサーバーへの通信を制限する
  6. show コマンドとPing・HTTPで結果を検証する
  7. 設定ミスを想定した障害切り分けと修正を記録する

04 / 基本通信テスト（利用者実測）

通信パターン期待結果実測
社員 → 業務サーバー許可期待どおり
ゲスト → 業務サーバー拒否未検証
各端末 → 自VLANのGW到達可能未検証
許可されたネットワーク間の経路確認可能未検証

必須テストは9件（T01〜T08、T10）で期待どおり。サーバー発の新規TCP（T09）は追加試験として未実施。拒否時のTimeoutは、正常系とACL設定記録を合わせて判断しました。

05 / 障害切り分けの実測

演習障害時復旧確認
TrunkからVLAN20を除外社員→WEB Ping 0/4VLAN20再追加後 4/4
社員PCのGW誤設定異VLAN WEB Ping 0/4GW修正後 4/4
HTTP許可ACLを削除Ping疎通あり・HTTP TimeoutACL復旧後HTTP表示

障害を意図的に発生させ、showコマンドや端末設定をもとに原因を絞り込み、修正後の再試験まで記録しました。

06 / 設計資料・検証記録

  • 要件定義・VLAN/IP設計
  • Cisco CLI・検証手順
  • 通信テスト・障害演習の実測記録

構築ファイル（.pkt）は利用者から受領済みですが、GitHubでの配布は準備中です。実測は利用者がPacket Tracerで実施したもので、公開元による別環境での再試験は未実施です。

07 / このプロジェクトで伝えたいこと

目的を読み解き、構成として整理し、設定だけでなく確認方法まで設計する姿勢を重視しています。ネットワークの知識を、再現可能な技術資料として示すことを目指します。
